# Car Radio and Menu Music Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A car radio during a run, with two stations: Rhyflitzer FM (four committed tracks) and SRF 3 live (with a
fallback). Keys 5–0 control it on desktop, a 📻 panel on phones, and a 3 s display shows each change. The start
screen gets quiet menu music, loaded only after the first input.

**Architecture:** Pure rules live in a new `radio.js`, unit-tested with `node --test`, like `sound.js` and
`controls.js`. A `RADIO` IIFE next to `SFX` in `index.html` routes three lazily created `<audio>` elements through
their own gains into the SFX master gain. It polls `R.state` to know whether a run is on, and follows `SFX.hold`
(pause menu, hidden tab).

**Tech Stack:** Vanilla ES modules, Web Audio (`MediaElementSource`), `node --test`, pytest + Playwright.

**Spec:** `docs/superpowers/specs/2026-11-09-car-radio-design.md`

## Global Constraints

- The music files **already exist** in `assets/music/`, together with their `.LICENSE.md` files:
  - `cool-rider.mp3`
  - `neon-afterglow.mp3`
  - `california-snares-and-synths.mp3`
  - `menu-running-title.mp3`

  **Do not download, re-encode or rename anything.**
- SRF 3 URL: exactly `https://stream.srg-ssr.ch/srgssr/srf3/mp3/128`. Never use `https://stream.srg-ssr.ch/m/drs3/mp3_128`,
  because it redirects to `http://`. Play it unchanged: no proxy, no re-hosting, no cutting.
- Default station `fm` (Rhyflitzer FM), radio on, volume step 6 of 10, menu music on.
- localStorage keys `mm.radio`, `mm.radioStation`, `mm.radioVol`, `mm.menuMusic`. Every access is in `try/catch`.
- Radio keys: Digit5 on/off, Digit6 station, Digit7 prev, Digit8 next, Digit9 volume −, Digit0 volume +. No action
  while Shift, Ctrl, Alt or Meta is held. **M stays the global mute.**
- No new permanent HUD widget on desktop (maintainer, 2026-11-09). The display reuses `#toast` for 3 s.
- Strings in **en and de** (`strings.js`), Swiss spelling (no ß).
- No framework, no package, no build step. Never `run_in_background` for Playwright. Commit and push the branch
  before running browser tests.
- **No browser test may reach the real SRF stream.** `tests/hermetic_api.py` aborts `*.srg-ssr.ch` for every
  context, and tests that need a stream stub it with `page.route`.
- Run only the targeted tests listed per task. Do not run the full Playwright suite (~2 h).
- Line numbers below were read on `main` at 633e17e. Find each spot by its quoted code, not by the number alone.

## Review Focus

1. **Quick repeated 7/8 presses** while a track is still loading: `play()` rejects with "interrupted by a new load
   request". That rejection must be caught. Expect no `pageerror` and the right final track. Test: Task 8
   `test_keys_drive_the_radio_and_show_the_display` presses 8 five times.
2. **Shift+0 on a Swiss keyboard** types `=` (minimap zoom) and Shift is the held nitro key. The volume must not
   change. Tests: Task 1 `radioKeyAction` modifier test and Task 8 (Shift+0 keeps the volume).
3. **SRF 3 stalls after it has started**: it must fall back to FM and never hang. Tests: Task 1 `srfVerdict` stall
   test, and Task 8's fallback test for the "never starts" case.
4. **Pause during SRF 3**: after Resume the stream must play live again, not stay silent. Test: Task 8
   `test_pause_pauses_and_resumes_the_radio` with the SRF stub.
5. **Corrupt or missing stored values** (private mode, old values): use the defaults and never throw. Test: Task 1
   `*From` tests.

```js
// radio.js (#735): the car radio (Rhyflitzer FM, SRF 3 live) and the start screen's menu music.
// Pure: no DOM, no audio -- node --test imports it; the RADIO IIFE in index.html plays what these rules say.

// NOT the short https://stream.srg-ssr.ch/m/drs3/mp3_128: it redirects to plain http://, blocked as mixed content
export const SRF3_URL = 'https://stream.srg-ssr.ch/srgssr/srf3/mp3/128';
export const STATIONS = Object.freeze(['fm', 'srf3']);
// the four tracks without Content ID; licences in assets/music/<id>.LICENSE.md. gainDb evens out the levels
// (ffmpeg volumedetect 2026-11-09: Cool Rider -10.1 dB mean, the others about -16 dB)
export const TRACKS = Object.freeze([
  { id: 'cool-rider', title: 'Cool Rider', artist: 'Emmraan', src: 'assets/music/cool-rider.mp3', gainDb: -6 },
  { id: 'neon-afterglow', title: 'Neon Afterglow', artist: 'MemoryArcade', src: 'assets/music/neon-afterglow.mp3', gainDb: 0 },
  { id: 'california-snares-and-synths', title: 'California Snares and Synths', artist: 'Eliza_music', src: 'assets/music/california-snares-and-synths.mp3', gainDb: 0 },
  { id: 'menu-running-title', title: 'Menu / Running Title', artist: 'Rob Bery', src: 'assets/music/menu-running-title.mp3', gainDb: 0 },
]);
export const MENU_TRACK = TRACKS[3];
export const VOLUME = Object.freeze({ min: 0, max: 10, start: 6 });
const RADIO_BASE = 0.8, MENU_SHARE = 0.35;   // full volume into the SFX master; the menu music plays at 35 % of the radio
export const SRF_TIMEOUT = Object.freeze({ start: 8, stall: 10 });   // seconds without 'playing' after play(), and in 'waiting'/'stalled'
export const RADIO_SHOW_S = 3;   // the radio display in #toast
export const RADIO_STORE = Object.freeze({ on: 'mm.radio', station: 'mm.radioStation', vol: 'mm.radioVol', menu: 'mm.menuMusic' });

// the top-row digits 5-0: free in every run context (the lift pads take 0-9 only while open, and run first)
const KEY_ACTIONS = { Digit5: 'power', Digit6: 'station', Digit7: 'prev', Digit8: 'next', Digit9: 'down', Digit0: 'up' };
export const RADIO_KEYS = Object.freeze(Object.keys(KEY_ACTIONS));
const REPEATS = new Set(['down', 'up']);

// e = { code, shiftKey, ctrlKey, altKey, metaKey, repeat } → an action, 'ignore' (a held key, swallowed) or null (not ours).
// A modifier makes it not ours: Shift is the held nitro, and Shift+0 is '=' (minimap zoom) on a Swiss keyboard
export function radioKeyAction(e) {
  const action = KEY_ACTIONS[e.code];
  if (!action || e.shiftKey || e.ctrlKey || e.altKey || e.metaKey) return null;
  if (e.repeat && !REPEATS.has(action)) return 'ignore';
  return action;
}

export const nextTrack = (i, n = TRACKS.length) => (i + 1) % n;
export const prevTrack = (i, n = TRACKS.length) => (i - 1 + n) % n;
export const stepVolume = (vol, step) => Math.max(VOLUME.min, Math.min(VOLUME.max, vol + step));

// a square law, so the low steps stay usable
export const trackGain = (vol, gainDb = 0) => RADIO_BASE * (vol / VOLUME.max) ** 2 * 10 ** (gainDb / 20);
export const menuGain = (vol) => MENU_SHARE * trackGain(vol, MENU_TRACK.gainDb);

export const radioOnFrom = (stored) => stored !== '0';
export const menuMusicOnFrom = (stored) => stored !== '0';
export const stationFrom = (stored) => (STATIONS.includes(stored) ? stored : 'fm');
export function volumeFrom(stored) {
  if (stored === null || stored === undefined || stored === '') return VOLUME.start;
  const n = Number(stored);
  return Number.isInteger(n) && n >= VOLUME.min && n <= VOLUME.max ? n : VOLUME.start;
}

// watch = { since: play() asked at (s), playing: 'playing' fired, waitingSince: 'waiting'/'stalled' since (s) or null, error }
export function srfVerdict(watch, now) {
  if (watch.error) return 'fail';
  if (!watch.playing) return now - watch.since > SRF_TIMEOUT.start ? 'fail' : 'wait';
  if (watch.waitingSince !== null && now - watch.waitingSince > SRF_TIMEOUT.stall) return 'fail';
  return 'ok';
}

// the strings.js key and arguments the radio display shows for a state
export function displayFor(s) {
  if (!s.on) return { key: 'radioOff', args: [] };
  if (s.station === 'srf3') return { key: 'radioStationSrf', args: [] };
  const t = TRACKS[s.track];
  return { key: 'radioTrack', args: [t.title, t.artist] };
}
```

```python
"""#735: the car radio and the menu music in a real browser. Hand layout (terrain and world blocked), autoplay allowed.
The SRF 3 stream is never reached: hermetic_api aborts *.srg-ssr.ch, and the stub tests answer it with a local mp3.
Slow (Playwright): run in the foreground."""
from pathlib import Path

from playwright.sync_api import sync_playwright

ROOT = Path(__file__).parents[1]
MMH_ROUTE = "**/data/terrain_hochrhein.mmh"
ARGS = ["--use-angle=swiftshader", "--enable-unsafe-swiftshader", "--ignore-gpu-blocklist", "--autoplay-policy=no-user-gesture-required"]
SRF = "https://stream.srg-ssr.ch/srgssr/srf3/mp3/128"
STUB_MP3 = (ROOT / "assets/music/california-snares-and-synths.mp3").read_bytes()
T = 120000


def stub_srf(page, hits):
    def answer(route):
        hits.append(route.request.url)
        route.fulfill(status=200, headers={"Access-Control-Allow-Origin": "*", "Content-Type": "audio/mpeg"}, body=STUB_MP3)
    page.route(SRF, answer)


def open_game(p, server, srf_hits=None, touch=False):
    b = p.chromium.launch(args=ARGS)
    ctx = b.new_context(viewport={"width": 390, "height": 844} if touch else {"width": 1280, "height": 720}, has_touch=touch)
    page = ctx.new_page()
    errors, music = [], []
    page.on("pageerror", lambda e: errors.append(str(e)))
    page.on("request", lambda r: music.append(r.url) if "/assets/music/" in r.url else None)
    page.route(MMH_ROUTE, lambda r: r.fulfill(status=404, body=""))
    page.route("**/data/world_hochrhein.json", lambda r: r.fulfill(status=404, body=""))
    if srf_hits is not None:
        stub_srf(page, srf_hits)
    page.goto(f"{server}/index.html")
    page.wait_for_function("() => window.__mm && window.__mm.radio && document.querySelector('#worldstatus')?.textContent", timeout=240000)
    return b, page, errors, music


def radio(page):
    return page.evaluate("() => window.__mm.radio()")


def start_run(page):
    page.click("#startbtn", timeout=180000)
    page.wait_for_function("() => window.__mm.radio().inRun", timeout=T)


def test_menu_music_loads_only_after_the_first_input(server):
    with sync_playwright() as p:
        b, page, errors, music = open_game(p, server)
        page.wait_for_timeout(1500)
        assert music == [], music                       # nothing fetched while loading or idling on the start screen
        page.keyboard.press("Shift")                    # any first input arms it
        page.wait_for_function("() => window.__mm.radio().playing.menu", timeout=T)
        assert all("menu-running-title.mp3" in u for u in music), music
        page.click("#musicbtn")
        page.wait_for_function("() => !window.__mm.radio().menuOn", timeout=T)
        assert page.evaluate("() => localStorage.getItem('mm.menuMusic')") == "0"
        assert "Music: off" in page.inner_text("#musicbtn") or "Musik: aus" in page.inner_text("#musicbtn")
        assert errors == [], errors
        b.close()


def test_keys_drive_the_radio_and_show_the_display(server):
    with sync_playwright() as p:
        b, page, errors, music = open_game(p, server)
        start_run(page)
        page.wait_for_function("() => window.__mm.radio().playing.fm && !window.__mm.radio().playing.menu", timeout=T)
        t = page.evaluate("() => window.__mm.toast()")
        assert "Cool Rider" in t["text"] and t["shown"], t
        assert page.evaluate("() => document.getElementById('toast').classList.contains('radio')")
        page.keyboard.press("8")
        assert radio(page)["track"] == 1 and "Neon Afterglow" in page.evaluate("() => window.__mm.toast().text")
        page.keyboard.press("7")
        assert radio(page)["track"] == 0
        for _ in range(5):                              # Review Focus 1: rapid skips while loading never throw
            page.keyboard.press("8")
        assert radio(page)["track"] == 1
        vol = radio(page)["vol"]
        page.keyboard.press("0")
        assert radio(page)["vol"] == vol + 1
        page.keyboard.press("Shift+0")                  # Review Focus 2: Shift+0 is not the radio
        assert radio(page)["vol"] == vol + 1
        page.keyboard.press("5")
        page.wait_for_function("() => !window.__mm.radio().on && !window.__mm.radio().playing.fm", timeout=T)
        assert page.evaluate("() => localStorage.getItem('mm.radio')") == "0"
        page.wait_for_function("() => !window.__mm.toast().shown", timeout=T)   # the display fades after 3 s
        assert errors == [], errors
        b.close()


def test_srf3_plays_the_stubbed_stream(server):
    with sync_playwright() as p:
        hits = []
        b, page, errors, music = open_game(p, server, srf_hits=hits)
        start_run(page)
        page.keyboard.press("6")
        page.wait_for_function("() => window.__mm.radio().playing.srf && !window.__mm.radio().playing.fm", timeout=T)
        r = radio(page)
        assert r["station"] == "srf3" and r["src"]["srf"] == "https://stream.srg-ssr.ch/srgssr/srf3/mp3/128", r
        assert hits and all(u.startswith("https://stream.srg-ssr.ch/") for u in hits), hits
        assert "SRF 3 live" in page.evaluate("() => window.__mm.toast().text")
        page.keyboard.press("8")                        # no tracks on a live station: the display only
        assert radio(page)["track"] == 0
        assert errors == [], errors
        b.close()


def test_srf3_failure_falls_back_to_rhyflitzer_fm(server):
    with sync_playwright() as p:
        b, page, errors, music = open_game(p, server)   # no stub: hermetic_api aborts the stream
        start_run(page)
        page.keyboard.press("6")
        page.wait_for_function("() => window.__mm.radio().failed === 1 && window.__mm.radio().station === 'fm'", timeout=T)
        page.wait_for_function("() => window.__mm.radio().playing.fm", timeout=T)
        assert "SRF 3" in page.evaluate("() => window.__mm.toast().text")
        assert page.evaluate("() => localStorage.getItem('mm.radioStation')") == "fm"
        assert errors == [], errors
        b.close()


def test_pause_pauses_and_resumes_the_radio(server):
    with sync_playwright() as p:
        hits = []
        b, page, errors, music = open_game(p, server, srf_hits=hits)
        start_run(page)
        page.keyboard.press("6")
        page.wait_for_function("() => window.__mm.radio().playing.srf", timeout=T)

        page.wait_for_function("() => window.__mm.radio().held && !window.__mm.radio().playing.srf", timeout=T)
        page.keyboard.press("Escape")

        assert errors == [], errors
        b.close()


def test_touch_radio_panel(server):
    with sync_playwright() as p:
        b, page, errors, music = open_game(p, server, touch=True)
        start_run(page)
        boxes = page.evaluate("""() => { const r = (s) => { const e = document.querySelector(s); if (!e || getComputedStyle(e).display === 'none') return null;
            const b = e.getBoundingClientRect(); return [b.left, b.top, b.right, b.bottom]; };
            return { radio: r('#radiobtn'), pause: r('#pausebtn'), tr: r('#tr'), br: r('#br'), menu: r('#tMenu') }; }""")
        assert boxes["radio"], boxes
        ov = lambda a, c: c and not (a[2] <= c[0] or c[2] <= a[0] or a[3] <= c[1] or c[3] <= a[1])
        for k in ("pause", "tr", "br", "menu"):
            assert not ov(boxes["radio"], boxes[k]), (k, boxes)
        page.tap("#radiobtn")
        assert page.is_visible("#radiopanel")
        page.tap("#radiopanel [data-radio=next]")
        assert radio(page)["track"] == 1
        page.tap("#radiopanel [data-radio=up]")
        assert radio(page)["vol"] == 7
        page.tap("#radiobtn")
        assert not page.is_visible("#radiopanel")
        assert errors == [], errors
        b.close()


def test_desktop_has_no_radio_widget(server):
    with sync_playwright() as p:
        b, page, errors, music = open_game(p, server)
```
