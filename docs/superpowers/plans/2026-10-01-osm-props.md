# OSM Street Furniture (Props) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Export lamps, hydrants, benches, bins, bike racks and recycling containers from OSM into the world file as `props`, and draw them in the prototype with lamps and hydrants as solid obstacles.

**Architecture:** `osm_read` additionally collects prop nodes; a new pure module `pipeline/world_props.py` classifies, filters by road reach, pushes props off the driving surface and orients benches/racks; `osm.py build` writes `props`. The prototype passes `props` through `layoutFromWorld` and draws one `InstancedMesh` per kind, adding small OBBs for lamps and hydrants.

**Tech Stack:** Python 3.12, pyosmium 4.3, shapely 2.1, pytest; three.js 0.170 buildless, Node 24 test runner, Playwright (Python) smoke tests.

**Spec:** `docs/superpowers/specs/2026-10-01-osm-props-design.md`

**Model routing:** Task 5 (prop models and their look) is a graphics task → dispatch on **Fable**. All other tasks: default model.

## Global Constraints

- Game frame and conventions as in `docs/11-pipeline-osm.md`: game x = east, z = south, metres; rotation `rot = atan2(dz, dx)`.
- Kinds exactly: `hydrant`, `lamp`, `bench`, `bin`, `bike_rack`, `glass_container`, `clothes_container`.
- Hydrants with `fire_hydrant:type=underground` or `pipe` are not props.
- Reach: distance from the prop to the nearest kept non-bridge road **edge** ≤ 15 m (`max_dist=15.0`).
- Edge rule: a prop inside a road band (distance to the centre line < `w/2 + 0.6`) is moved perpendicular to `w/2 + 0.6`; still inside any band afterwards → dropped; inside a bridge band → dropped.
- Solid kinds (OBB): `lamp` 0.3 × 0.3 m, `hydrant` 0.4 × 0.4 m. All other kinds: no collision (user decision 2026-10-01).
- World file: new key `props: [{kind, x, z, rot}]`, x/z rounded to 0.1, rot to 0.01; format stays `MMW1`.
- Hand-traced path (no world file) unchanged; no `rr()`/`rnd()` calls in prop code.
- Memory rule on the agent box: every Python/node/browser command under `systemd-run --user --scope -q -p MemoryMax=2G -p MemorySwapMax=0 …` (3G for browser runs).
- Browser tests in the foreground only; commit before running them.
- Commits: Conventional Commits, English, ending with the session's `Co-Authored-By` and `Claude-Session` lines. CHANGELOG entries hand-written, player voice, under `## [Unreleased]`.

## Review Focus

1. **A lamp mapped exactly on a road centre line** → ends at `w/2 + 0.6` on the road's right-hand side, never in the lane (Task 2 test).
2. **A prop in a junction** where moving out of one band lands in another → dropped, not left in the lane (Task 2 test).
3. **World file without `props` (older build)** → prototype loads with zero props, no error (Task 4 test).
4. **Solid prop near a bridge** → dropped when inside the bridge band; no invisible post on a deck (Task 2 test).
5. **Hand-traced layout** → no props, identical geometry hash (Task 5 check).

```python
"""Street furniture (props): OSM nodes/areas -> {kind, x, z, rot}, kept off the driving surface."""
from __future__ import annotations

import math
from collections import Counter

import shapely
from shapely.strtree import STRtree

SKIP_HYDRANT = {"underground", "pipe"}


def classify(tags) -> str | None:
    if tags.get("emergency") == "fire_hydrant":
        return None if tags.get("fire_hydrant:type") in SKIP_HYDRANT else "hydrant"
    if tags.get("highway") == "street_lamp":
        return "lamp"
    a = tags.get("amenity")
    if a == "bench":
        return "bench"
    if a == "waste_basket":
        return "bin"
    if a == "bicycle_parking":
        return "bike_rack"
    if a == "recycling":
        if tags.get("recycling:glass_bottles") == "yes" or tags.get("recycling:glass") == "yes":
            return "glass_container"
        if tags.get("recycling:clothes") == "yes":
            return "clothes_container"
    return None


def _segments(roads):
    segs = []
    for r in roads:
        p = r["pts"]
        for i in range(len(p) - 1):
            segs.append((shapely.LineString([p[i], p[i + 1]]), r))
    return segs


def _side_and_normal(seg, x, z):
    (ax, az), (bx, bz) = seg.coords
    dx, dz = bx - ax, bz - az
    L = math.hypot(dx, dz) or 1.0
    nx, nz = -dz / L, dx / L                       # right-hand normal (x east, z south)
    s = (x - ax) * nx + (z - az) * nz
    return (1.0 if s >= 0 else -1.0), nx, nz, math.atan2(dz, dx)


def build(prop_nodes, areas, roads, clip, max_dist=15.0, edge_gap=0.6):
    items = [(classify(n.tags), n.x, n.z) for n in prop_nodes]
    for a in areas:
        k = classify(a.tags) if a.tags.get("amenity") in ("bicycle_parking", "recycling") else None
        if k:
            c = a.geom.centroid
            items.append((k, c.x, c.y))
    segs = _segments(roads)
    geoms = [g for g, _ in segs]
    tree = STRtree(geoms) if geoms else None
    stats, out = Counter(), []
    for kind, x, z in items:
        if kind is None:
            stats["unclassified"] += 1
            continue
        p = shapely.Point(x, z)
        if not clip.contains(p):
            continue
        near = [segs[i] for i in tree.query(p, predicate="dwithin", distance=max_dist + 10)] if tree else []
        drive = [(g, r) for g, r in near if not r["bridge"]]
        if any(g.distance(p) < r["w"] / 2 + edge_gap for g, r in near if r["bridge"]):
            stats["on_bridge"] += 1
            continue
        if not drive or min(g.distance(p) - r["w"] / 2 for g, r in drive) > max_dist:
            stats["out_of_reach"] += 1
            continue
        g, r = min(drive, key=lambda gr: gr[0].distance(p))
        side, nx, nz, ang = _side_and_normal(g, x, z)
        if g.distance(p) < r["w"] / 2 + edge_gap:
            foot = g.interpolate(g.project(p))
            off = side * (r["w"] / 2 + edge_gap)
            x, z = foot.x + nx * off, foot.y + nz * off
            p = shapely.Point(x, z)
            if any(gg.distance(p) < rr["w"] / 2 + edge_gap - 1e-6 for gg, rr in near):
                stats["still_on_road"] += 1
                continue
            stats["moved_to_edge"] += 1
        rot = ang if kind in ("bench", "bike_rack") else 0.0
        out.append({"kind": kind, "x": round(x, 1), "z": round(z, 1), "rot": round(rot, 2)})
        stats["kept_" + kind] += 1
    return out, dict(stats)
```
