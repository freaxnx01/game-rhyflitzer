# German and English UI (i18n DE/EN) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every user-facing UI text of `prototype/index.html` exists in English and German, switchable live with the house `EN/DE` toggle in `#game-nav`; the fishes toast follows the game language.

**Architecture:** The house `i18n.js` (copied verbatim from `.ai/stacks/browser-game.md`) owns language detection, the shared `gg-lang` key and the toggle. A new pure ES module `prototype/strings.js` owns the game's `STRINGS` table and `translate(lang, key, ...args)`. The inline module script in `index.html` gets a `tr()` wrapper, a `data-i18n` walker for static markup, small render functions for state-dependent text, and one `gg-langchange` listener that re-renders.

**Tech Stack:** Vanilla JS (ES modules, no build), three.js from CDN (untouched), `node --test` for pure modules, pytest + Playwright (Chromium, swiftshader) for the page.

**Spec:** [`docs/superpowers/specs/2026-10-02-i18n-de-en-design.md`](../specs/2026-10-02-i18n-de-en-design.md)

## Global Constraints

- Buildless: no framework, no bundler, no `package.json`, no new dependency.
- `prototype/i18n.js` is a **verbatim** copy of the `i18n.js` block in `.ai/stacks/browser-game.md` → "Localization (i18n)" (it includes the `btn.blur()` fix). Do not edit it.
- Loaded as a classic script **right after** `<script src="./version.js"></script>`.
- The translator in `index.html` is named **`tr`**, not `t`: the module script uses `t` as a local variable in many functions (`finish`, `randomSpot`, `jumpTo`, the map `pointerdown` handler), and a shadowed `t('key')` would throw.
- German: Swiss spelling (`ss`, never `ß`), real umlauts, address pronouns capitalised (`Du`, `Deine`).
- Never translated: checkpoint/finish/place names (`CPS[].n`, `FINISH.n`, `PLACES[].n`), street names, all 3D world labels, minimap place labels, "Map Madness", "Rhyflitzer", the hub links in `#game-nav`, `<kbd>` key captions, the `window.__mm` test hooks.
- English output must stay byte-identical to today's texts — the existing suite asserts on them (`"Camera: Chase near"`, `"Terrain: measured ·"`, `"traced by hand"`, `"Random spot"`, `"zoom the map"`, `"Nitro"`, `"Turn signals"`, `"4×"`).
- Elements whose text is state-dependent (`#ovtext`, `#startbtn`, `#stylebtn2`, `#mmhstatus`, `#blurb`, `#worldstatus`, `#result`, `#best`, `#odo`) get **no** `data-i18n` attribute — the walker would clobber their state. (`#cpname` does get `data-i18n="ready"` for its pre-race text; `hud()` overwrites it every frame once a target exists.)

## Review Focus

- A language click **before** the module script has finished loading (world/terrain fetch takes seconds): the listener is not registered yet, so the module must re-render once when it registers it → Task 3 calls `rerenderAll()` right after `addEventListener('gg-langchange', …)`; covered by the stored-language test (language fixed before load).
- Pressing **Enter** (horn) or **Space** after clicking the toggle must not flip the language back → Task 3 test `test_enter_after_toggle_keeps_language`.
- Switching language on the **result screen** must keep the record line (time, best, "not counted" notes) → Task 3 test `test_result_screen_rerenders`.
- `i18n.js` missing / `GG_LANG` undefined: `translate(undefined, …)` must fall back to English, never throw → Task 1 unit test.
- `localStorage` blocked: `i18n.js` already wraps it in try/catch; the page must still load English/browser language → covered by i18n.js verbatim; no extra test (Playwright cannot block storage per origin cheaply).

```js
import { test } from 'node:test';
import assert from 'node:assert/strict';
import { STRINGS, translate } from '../strings.js';

test('English and German have exactly the same keys', () => {
  assert.deepEqual(Object.keys(STRINGS.de).sort(), Object.keys(STRINGS.en).sort());
});

test('every value is a string or a function in both languages, and functions agree on arity', () => {
  for (const key of Object.keys(STRINGS.en)) {
    const en = STRINGS.en[key], de = STRINGS.de[key];
    assert.ok(['string', 'function'].includes(typeof en), key);
    assert.equal(typeof de, typeof en, key);
    if (typeof en === 'function') assert.equal(de.length, en.length, key);
  }
});

test('German strings use Swiss spelling (no sharp s)', () => {
  for (const [key, v] of Object.entries(STRINGS.de)) {
    const s = typeof v === 'function' ? v(...Array(v.length).fill('x')) : v;
    assert.ok(!s.includes('ß'), key);
  }
});

test('translate picks the language, falls back to English, then to the key', () => {
  assert.equal(translate('de', 'fishes'), 'Grüss mir die Fische!');
  assert.equal(translate('en', 'fishes'), 'Sleep with the fishes!');
  assert.equal(translate('fr', 'fishes'), 'Sleep with the fishes!');
  assert.equal(translate(undefined, 'fishes'), 'Sleep with the fishes!');
  assert.equal(translate('de', 'no-such-key'), 'no-such-key');
});

test('function values interpolate their arguments; names pass through untouched', () => {
  assert.equal(translate('de', 'cpTarget', 2, 'Bahnhof Sisseln'), 'Checkpoint 2 · Bahnhof Sisseln');
  assert.equal(translate('en', 'finishTarget', 'Münsterplatz'), 'Finish · Münsterplatz');
  assert.equal(translate('de', 'finishTarget', 'Münsterplatz'), 'Ziel · Münsterplatz');
  assert.equal(translate('en', 'camera', translate('en', 'camNear')), 'Camera: Chase near');
  assert.equal(translate('de', 'camera', translate('de', 'camNear')), 'Kamera: Verfolger nah');
  assert.equal(translate('en', 'best', null), 'Best —');
  assert.equal(translate('de', 'best', '01:02.3'), 'Bestzeit 01:02.3');
});

test('English texts stay exactly as the existing tests expect', () => {
```

```python
"""#9 German and English UI: EN/DE toggle in #game-nav (house i18n.js, shared gg-lang key), the browser language as
fallback, live re-render without reload, the toggle's blur fix (Enter honks), and the fishes toast following the game
language. Hand-traced layout (world + terrain blocked): no data files needed, deterministic."""
import pytest
from playwright.sync_api import sync_playwright

MMH_ROUTE = "**/data/terrain_hochrhein.mmh"
ARGS = ["--use-angle=swiftshader", "--enable-unsafe-swiftshader", "--ignore-gpu-blocklist"]
READY = "() => window.__mm && window.__mm.sim && document.querySelector('#worldstatus')?.textContent"


def open_page(p, server, locale="en-US", lang=None):
    """lang: a gg-lang value stored before the page's own scripts run (on every navigation of this context)."""
    b = p.chromium.launch(args=ARGS)
    ctx = b.new_context(locale=locale, viewport={"width": 1280, "height": 720})
    if lang:
        ctx.add_init_script(f"try {{ localStorage.setItem('gg-lang', '{lang}'); }} catch (e) {{}}")
    page = ctx.new_page()
    errors = []
    page.on("pageerror", lambda e: errors.append(str(e)))
    page.route(MMH_ROUTE, lambda r: r.fulfill(status=404, body=""))
    page.route("**/data/world_hochrhein.json", lambda r: r.fulfill(status=404, body=""))
    page.goto(f"{server}/prototype/index.html")
    page.wait_for_function(READY, timeout=240000)
    return b, page, errors


def text(page, sel):
    return page.text_content(sel)


@pytest.mark.parametrize("locale,lang,mode,status", [
    ("de-CH", "de", "Zeitfahren · Hochrhein", "Gelände: erfunden"),
    ("en-US", "en", "Time trial · Hochrhein", "Terrain: made up"),
])
def test_browser_language_decides_without_a_stored_choice(server, locale, lang, mode, status):
    with sync_playwright() as p:
        b, page, errors = open_page(p, server, locale=locale)
        got = page.evaluate("""() => ({ lang: window.GG_LANG, html: document.documentElement.lang,
            toggle: document.querySelector('#game-nav #gg-lang-toggle')?.textContent })""")
        shown_mode, shown_status = text(page, "#tl .mode"), text(page, "#mmhstatus")
        b.close()
    assert got == {"lang": lang, "html": lang, "toggle": lang.upper()}
    assert shown_mode == mode and shown_status.startswith(status), (shown_mode, shown_status)
    assert errors == []


def test_stored_language_wins_over_the_browser(server):
    with sync_playwright() as p:
        b, page, errors = open_page(p, server, locale="en-US", lang="de")
        shown = page.evaluate("""() => ({
            help: document.querySelector('#help').textContent,
            jumpTitle: document.querySelector('#jump > div').textContent,
            east: document.querySelector('#rose text:nth-of-type(2)').textContent,
            compass: document.querySelector('#compass').getAttribute('aria-label'),
            map: document.querySelector('#br .bar span').textContent,
            loadTerrain: document.querySelector('label[for=mmhfile]').textContent,
        })""")
        b.close()
    assert "Blinker links · rechts" in shown["help"] and "Tasten · F1 schliesst" in shown["help"], shown["help"]
    assert shown["jumpTitle"] == "Springen nach"
    assert shown["east"] == "O" and shown["compass"] == "Kompass"
    assert shown["map"].startswith("Karte · Hochrhein ·")
    assert shown["loadTerrain"] == "Gelände laden (.mmh)"
    assert errors == []
```
