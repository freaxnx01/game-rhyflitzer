# On Foot (Z) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `Z` gets out of the stopped car; you walk with gravity or hover (F toggles, Space up, Shift down) in first person, collide
with the car's colliders, and `Z` next to the parked car gets back in (#202).

**Architecture:** Copy the helicopter pattern (`FLY` + pure `heli.js`): a `FOOT` state object in `prototype/index.html`, `P` is
the walker, a pure model in a new `prototype/foot.js`, a third branch in the main loop and in `stepCamera`, `resetCar()` ends it.
The car mesh simply stays where `stepCar` last put it. The collider shape math moves out of `collide()` into a pure
`colliderPush` in `prototype/world.js`, shared by the car and the walker.

**Tech Stack:** vanilla JS ES modules, three.js (already loaded), `node --test` for pure helpers, Playwright (Python) for one
targeted browser file.

**Spec:** `docs/superpowers/specs/2026-10-17-on-foot-design.md`

## Global Constraints

- Buildless game: no package.json, no bundler, no new dependency.
- `Z` is matched by `e.key` (`'z'` / `'Z'`), never by `e.code` — the Z label on QWERTZ (`KeyY`) and QWERTY (`KeyZ`).
- `P` stays the position (map, compass, HUD follow it), like the helicopter (`index.html:1930`).
- Strings in both `en` and `de` of `prototype/strings.js`; German with real umlauts and Swiss `ss` ("zu Fuss"), never `ß`.
- A run with a get-out is not clean: no best, no rank; checkpoints, the finish and presents don't count on foot.
- Touch is out of scope: no touch button, no touch look.
- Tests: node tests in `prototype/tests/foot.test.mjs`; ONE new Playwright file `prototype/tests/test_on_foot.py`. No full suite.

## Review Focus

1. **Esc while the mouse is locked** must open the pause exactly once (Chrome swallows that keydown; the `pointerlockchange`
   handler opens it) — and getting back in with Z must *not* open the pause (`endFoot` sets `FOOT.on = false` before
   `exitPointerLock`). Covered by Task 5's `footLock` checks in `test_on_foot.py` (the unlock path is simulated through the hook).
2. **Teleports on foot** (R, J, map double-click, Start/Restart) must end the mode and put you back in the car — `resetCar()`
   calls `endFoot()`. Covered in Task 4 test 1 (R on foot).
3. **Getting out where there is no room** (car parked against a wall / at the water) must refuse with a toast, not drop you
   inside a building — `exitSpots` + `footFree`. The spot order is node-tested (`exitSpots_…`); the refusal itself is not
   automated: reviewer reads `footFree` (water check + `footBlocks` + `colliderPush`) and the manual check covers it.
4. **Bridge parapets** must still block a walker on the deck: their `h` is a constant 2, not a height, so the "box top below
   your feet" rule must not apply to `o.bridge`. `footBlocks` (Task 4) returns early for bridges; `footFloor_Bridge_Ignored`
   covers the floor side. Reviewer: check the early return stays before the `y >= o.h` rule.
5. **Hover above a roof, then F to walk** must land you *on* the roof, not inside the building. Covered by Task 4 test 2.

```js
// #202: on foot (Z) -- the walker's pure model, no three.js, no DOM. Unit-tested with `node --test prototype/tests/*.test.mjs`.
// Same frame as the car: x east, z south, th = heading (0 = +x, grows to the right). Units m, m/s, m/s², rad.
export const WALKER = { eye: 1.7, radius: 0.35, walk: 4.5, hover: 11, climb: 6, turnRate: 2.2, gravity: 22, jumpV: 6, stepUp: 0.6, enterReach: 2.5, exitGap: 0.6, mouse: 0.0025, pitchMax: 1.4, hoverMaxAgl: 150 };

const held = (keys, codes) => codes.some(c => keys[c]);
const axis = (plus, minus) => (plus ? 1 : 0) - (minus ? 1 : 0);
const clamp = (v, lo, hi) => Math.max(lo, Math.min(hi, v));

// W/S or up/down walk, A/D sidestep, left/right turn (the keyboard-only look), Space up (or jump), Shift down
export function footInput(keys) {
  return {
    fwd: axis(held(keys, ['KeyW', 'ArrowUp']), held(keys, ['KeyS', 'ArrowDown'])),
    side: axis(held(keys, ['KeyD']), held(keys, ['KeyA'])),
    turn: axis(held(keys, ['ArrowRight']), held(keys, ['ArrowLeft'])),
    lift: axis(held(keys, ['Space']), held(keys, ['ShiftLeft', 'ShiftRight'])),
  };
}

// one fixed step: turn, move along the heading (diagonals not faster), then the height -- floorAt(x, z, y) is asked at the new spot
export function stepFoot(s, input, dt, floorAt, cfg = WALKER) {
  const th = s.th + input.turn * cfg.turnRate * dt, fx = Math.cos(th), fz = Math.sin(th);
  let mx = input.fwd * fx - input.side * fz, mz = input.fwd * fz + input.side * fx;
  const m = Math.hypot(mx, mz); if (m > 1) { mx /= m; mz /= m; }
  const speed = s.hover ? cfg.hover : cfg.walk, vx = mx * speed, vz = mz * speed, x = s.x + vx * dt, z = s.z + vz * dt;
  const moved = { ...s, x, z, th, vx, vz }, floor = floorAt(x, z, s.y);
  return s.hover ? hoverStep(moved, input, dt, floor, cfg) : walkStep(moved, input, dt, floor, cfg);
}

function hoverStep(s, input, dt, floor, cfg) { return { ...s, vy: 0, y: Math.max(floor, s.y + input.lift * cfg.climb * dt) }; }

// on the ground (within stepUp above the floor and not rising) you stick to it, and Space jumps; in the air gravity pulls
function walkStep(s, input, dt, floor, cfg) {
  const grounded = s.y - floor <= cfg.stepUp && s.vy <= 0;
  if (grounded && input.lift <= 0) return { ...s, y: floor, vy: 0 };
  const vy = grounded ? cfg.jumpV : s.vy - cfg.gravity * dt, y = s.y + vy * dt;
  return y <= floor ? { ...s, y: floor, vy: 0 } : { ...s, y, vy };
}

const inside = (o, x, z) => {
  const dx = x - o.x, dz = z - o.z;
  if (o.circle) return Math.hypot(dx, dz) <= o.circle;
  return Math.abs(dx * o.c + dz * o.s) <= o.hw && Math.abs(-dx * o.s + dz * o.c) <= o.hd;
};

// the floor under the walker: the ground, or the top of a non-bridge box under you that is at most stepUp above your feet
export function footFloor(ground, boxes, x, z, y, cfg = WALKER) {
  let top = ground;
  for (const o of boxes) if (!o.bridge && o.h <= y + cfg.stepUp && o.h > top && inside(o, x, z)) top = o.h;
  return top;
}

// mouse look: right turns right (th grows, like D steering), up looks up; pitch clamped
export function footLook(th, pitch, dx, dy, cfg = WALKER) {
  return { th: th + dx * cfg.mouse, pitch: clamp(pitch - dy * cfg.mouse, -cfg.pitchMax, cfg.pitchMax) };
}

// where you step out: left (driver's) side first, then right, behind, front -- each clear of the body by exitGap
export function exitSpots(car, size, cfg = WALKER) {
  const fx = Math.cos(car.th), fz = Math.sin(car.th), side = size.w / 2 + cfg.radius + cfg.exitGap, end = size.l / 2 + cfg.radius + cfg.exitGap;
  return [[fz, -fx, side], [-fz, fx, side], [-fx, -fz, end], [fx, fz, end]].map(([ux, uz, d]) => ({ x: car.x + ux * d, z: car.z + uz * d }));
}

// the parked car as a collider (same OBB shape as the world's: hw along the heading)
export function parkedBox(car, size) {
  return { x: car.x, z: car.z, hw: size.l / 2, hd: size.w / 2, c: Math.cos(car.th), s: Math.sin(car.th), h: car.y + size.h, parked: true };
}

export function carReach(x, z, b) {
  const dx = x - b.x, dz = z - b.z, lx = dx * b.c + dz * b.s, lz = -dx * b.s + dz * b.c;
  return Math.hypot(Math.max(0, Math.abs(lx) - b.hw), Math.max(0, Math.abs(lz) - b.hd));
}

// keydown on foot: F toggles hover; the car's own controls are swallowed; everything else is handled as usual
const FOOT_BLOCKED = new Set(['KeyC', 'KeyO', 'KeyI', 'KeyU', 'KeyH', 'Enter', 'NumpadEnter', 'KeyQ', 'KeyE', 'KeyL', 'Digit1', 'KeyV']);
export function footKeyAction(code) {
  if (code === 'KeyF') return 'hover';
  return FOOT_BLOCKED.has(code) ? 'block' : 'pass';
}
```

```js
// #202: the push-out of a circle (x, z, r) from one collider -- OBB, circle or ring -- as collide() has always computed it, now
// shared by the car (collide, which adds the impact response) and the walker (collideFoot, position only). null: no contact.
export function colliderPush(o, x, z, r) {
  if (o.ring) return ringPush(o.ring, x, z, r);
  const dx = x - o.x, dz = z - o.z;
  if (o.circle) { const dd = Math.hypot(dx, dz) || 1e-4; return dd > r + o.circle ? null : { wx: dx / dd, wz: dz / dd, pen: r + o.circle - dd }; }
  const lx = dx * o.c + dz * o.s, lz = -dx * o.s + dz * o.c;
  let nx = lx - Math.max(-o.hw, Math.min(o.hw, lx)), nz = lz - Math.max(-o.hd, Math.min(o.hd, lz)), d = Math.hypot(nx, nz);
  if (d > r) return null;
```
