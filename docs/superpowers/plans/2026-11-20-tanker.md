# Rhy Tanker (#1103) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A drivable heating-oil tanker whose drawbar trailer swings behind it.

**Architecture:** Pure `trailer.js` holds the drawbar kinematics (node-tested). `tools/prepare-tanker.mjs` turns the CC BY MAN TGX
cab into `assets/tanker.glb`, generating the chassis, tank and trailer, with the trailer in its own node pivoting at the hitch.
`tanker.js` is the vehicle entry; `index.html` turns the trailer node each frame from `trailer.js` (own car, remote cars),
leaves it straight when parked; `depot.js` `footprint` counts the trailer.

**Tech Stack:** vanilla JS ES modules, three.js r170 (index.html only), `@gltf-transform` + `meshoptimizer` (prepare tool only, run
outside the repo), `node --test`, Python Playwright.

**Spec:** `docs/superpowers/specs/2026-11-20-tanker-design.md`

### Task 1: drawbar kinematics

**Files:** Create `trailer.js`; Test `tests/trailer.test.mjs`

**Interfaces:**
- Produces: `export const TRAILER = { maxAngle }` and
  `export function trailerStep(phi: number, v: number, yawRate: number, geom: { hitch: number, length: number }, dt: number): number`
  — `phi` the trailer's angle relative to the truck (rad, + = trailer swung to the truck's left, i.e. +z side… use the game's
  heading convention from `foot.js`/`FOOT.car` and say which in the header comment), `v` signed speed along the truck's +x
  (m/s), `yawRate` the truck's heading rate (rad/s), `geom.hitch` the hitch's distance behind the truck origin (m),
  `geom.length` hitch to the trailer's effective axle (m). Returns the new angle, clamped to ±maxAngle.
  Single-pivot model: `dphi/dt = -yawRate - (v * sin(phi) + hitch * yawRate * cos(phi)) / length` (derive and check the signs
  against the tests; semi-implicit or sub-stepped so a 0.1 s frame stays stable).

- [ ] Step 1: tests — `straight driving brings the trailer back to 0` (phi 0.5, v 10, yawRate 0, 200 steps of 1/60 → |phi| < 0.01);
  `a steady circle settles at a steady angle on the inside` (v 8, yawRate 0.4, 600 steps → phi converged (last two steps differ
  < 1e-4) with sign showing the trailer inside the turn, |phi| < maxAngle); `reversing folds it up to the clamp` (phi 0.05, v -3,
  yawRate 0, 2000 steps → |phi| === maxAngle); `standing still changes nothing` (v 0, yawRate 0 → same phi; dt 0 → same phi);
  `a long frame stays finite and clamped` (dt 0.5, v 22, yawRate 1 → finite, |phi| ≤ maxAngle).
- [ ] Step 2: `node --test tests/trailer.test.mjs` → FAIL (module missing).
- [ ] Step 3: implement `trailer.js` (header in the style of `depot.js`).
- [ ] Step 4: `node --test tests/trailer.test.mjs` → pass.
