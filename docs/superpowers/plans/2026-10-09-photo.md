# Take a photo (#113) Implementation Plan

**Goal:** Key X saves the current 3D view as a PNG download. Spec: `docs/superpowers/specs/2026-10-09-photo-design.md`.

**Architecture:** pure `prototype/photo.js` (filename, gating), a pending flag set by the keydown handler, and a capture call right after `renderer.render` in `loop()`. Tests: `node --test prototype/tests/*.test.mjs`; one Playwright file run targeted in the foreground under a memory cap, not the full suite.

### Task 1: Pure module photo.js with unit tests

**Files:** create `prototype/photo.js`, `prototype/tests/photo.test.mjs`.

- [ ] Write the failing test `prototype/tests/photo.test.mjs`:

```js
import { test } from 'node:test';
import assert from 'node:assert/strict';
import { photoFileName, canPhoto } from '../photo.js';

test('photoFileName: local timestamp, zero-padded', () => {
  assert.equal(photoFileName(new Date(2026, 9, 9, 7, 5, 3)), 'rhyflitzer-20261009-070503.png');
});
test('canPhoto: only with the overlay hidden, the J/O search closed and no key repeat', () => {
  assert.equal(canPhoto(true, false, false), true);
  assert.equal(canPhoto(false, false, false), false);
  assert.equal(canPhoto(true, true, false), false);
  assert.equal(canPhoto(true, false, true), false);
});
```

- [ ] Run `node --test prototype/tests/photo.test.mjs`; expect failure (module missing).
- [ ] Implement `prototype/photo.js` (ES module, style of `pause.js`): `export function photoFileName(d)` returns `rhyflitzer-YYYYMMDD-hhmmss.png` from the local getters, zero-padded; `export function canPhoto(overlayHidden, jumpOpen, repeat) { return overlayHidden && !jumpOpen && !repeat; }`.
- [ ] Run the test; expect pass. Commit `feat(photo): pure filename and gating rules (#113)`.

**Files:** modify `prototype/index.html` (module imports, keydown `:1202`, `loop()` `:1527-1528`).
