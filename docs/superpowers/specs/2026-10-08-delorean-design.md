# DMC DeLorean look-alike as a vehicle (#126)

Status: quick enrichment 2026-10-08 (assumptions in the issue) · Issue #126 · builds on #5 (vehicle table), #69 (true-to-size car), #123/#133 (shared dark glass) · compatible with #132 (PR #139, steering wheels, open)

## Goal

A second entry in the `VEHICLES` table of `prototype/index.html`: a **DeLorean look-alike** built from three.js primitives in the same way as the compact — brushed stainless-steel body, the low wedge silhouette with the flat nose, quad rectangular headlamps, louvred rear window and engine deck, a black roof spine with **gull-wing doors that swing up while the car waits on the start screen** and close for the run. True to size (4.27 m × 1.86 m body / 2.0 m over the mirrors × 1.14 m), slower and a little more tail-happy than the compact. Reachable today via `?vehicle=delorean`; the picker is #7.

Success looks like:

- `VEHICLES.delorean` exists with the values under Decisions; `setVehicle(VEHICLES.delorean)` builds, drives, films, sounds, collides and rebuilds (no GPU leak) as a 4.27 m car.
- The compact keeps driving bit-for-bit as today (golden trace, 1e-6) and looks unchanged.
- No licensed asset, no logo, no lettering, no film reference anywhere: a look-alike from primitives (docs/07).

## Today (what the code does)

- `VEHICLES` has one entry, `compact` (`prototype/index.html:1086-1092`); `VEH` is the active copy (`:1093`), swapped with `setVehicle(def)` (`:1125`), which calls `checkVehicle` (`:1124`: `model` must be a key of `MODELS`, collision must be `circle`) and `buildCar` (`:1122`: `freeCar`, clear the persistent `car`, `flames`, `BLINK.left/right` groups, `car.scale = VEH.scale`, then `MODELS[VEH.model](car, VEH)`).
- `MODELS` is `{ compact: buildCompact }` (`:1117`). `buildCompact(g, v)` (`:1101-1116`) draws the body as an extruded side profile (`shape(pts)` + `ExtrudeGeometry`, bevel 0.07), the cabin as one dark extruded glass block tagged `userData.glass = true`, a sill box, two nitro cones into `flames`, the wheels from `v.wheels` (`[x, z]` mirrored to ±z) with tyre / rim / hub cylinders, head- and tail-lamp boxes, mirrors, a grille and a `textTex` number plate. Blinker boxes go into `BLINK[side]` (`:1102`).
- `carMats` (`:1100`) holds the shared materials `body` (navy Phong), `glass` (near-black opaque Phong, #123), `dark`, `rim`, `tyre`; they are in `SHARED_CAR_MATS` (`:1120`) so `freeCar` (`:1121`) never disposes them. Per-build materials and textures (the plate) are disposed by `freeCar`. `applyStyle` (`:1141`) flips `carMats.body.flatShading` for the `smooth` style — the only style hook on the car.
- The compact is drawn true to size (`:1098` comment, #69): `scale: 1.0`, 4.66 m long, 2.18 m over the mirrors, 1.55 m high; `window.__mm.carSize()` (`:1278`) measures the body box from the car's children minus `flames`, and `test_compact_car_is_true_to_size` pins it.
- Scene light is a hemisphere light plus one directional sun (`:1060-1061`); there is no environment map, so a `MeshStandardMaterial` with high `metalness` would render near-black. The `smooth` style uses tone mapping and shadows (`:1136`).
- `window.__mm` hooks for tests: `vehicles()`, `vehicle()`, `setVehicle(def)`, `carSize()`, `glass()`, `gpu()`, `cam()`, `hud()`, `sim(...)` (`:1270-1283`). `prototype/tests/test_vehicles.py` has `open_hand`, `use_vehicle` (patches a copy of compact), `wait_frames`, the golden trace, the #69 size test, the #123 glass test and the rebuild-leak test.
- **Selection today:** there is no way to pick a vehicle in the game. `setVehicle(VEH)` runs once at startup (`:1127`); only the test hook `__mm.setVehicle` swaps. #6 (spec + plan on `main`, not implemented) defines `vehicleFromQuery(search, ids)` in a new pure module `prototype/vehicle.js` and a startup line next to `debugFromQuery` (`:1459`) so `?vehicle=<id>` selects a table entry; #7 (car-select screen, enriched, not implemented) keeps `?vehicle=` as the way in and reads `VEHICLES` generically (its AC: a second table entry appears "without any change to the screen code").
- **#132 / PR #139 (open, not merged)** rewrites the wheel loop in `buildCompact`: each wheel becomes `steer group > roll group > tyre, rim, hub`, recorded in `g.userData.wheels = [{ front, steer, roll }]`, and `drawWheels()` in the loop writes the groups from `WHEEL_STATE`. `frontAxleX(v.wheels)` picks the front axle as the largest x. Pure helpers live in `prototype/steering.js`.
- Brand policy (`docs/07-brands-and-permissions.md:9-10`): no logo files until permission is given in writing; until then generic signage or a parody look-alike. The PostAuto row (`:23`) is the precedent for a vehicle: generic shape, no logo, lettering or livery, own horn.

## Tests

Node (`node --test prototype/tests/*.test.mjs`):

1. `vehicle.test.mjs` — `vehicleFromQuery`: known id, `?debug&vehicle=…`, unknown id, no parameter, empty string, `constructor` → exactly #6's test.
2. `delorean.test.mjs` — `profileSize(DELOREAN_BODY)` gives length 4.17 and top 1.09 (so 4.27 / 1.14 with the 0.05 bevel), every y ≥ 0.24; `DELOREAN_GLASS` lies inside the body's x range and below the roof; `louvreSlots` returns n evenly spaced points with the segment's tilt; `doorTarget` is 1 only for `'ready'` standing still; `stepDoor` approaches without overshoot, settles, and is frame-rate independent.

Playwright (`prototype/tests/test_vehicles.py`, foreground, memory-capped):

3. `test_delorean_is_in_the_table_and_true_to_size` — `setVehicle(vehicles().delorean)`, Start (doors close), wait until `doors().open < 0.01`, then `carSize()` ≈ 4.27 × 2.0 × 1.14 (±0.05; the bevelled roof at 1.14 is the highest point, the closed door roof halves and the spine stay under it).
4. `test_delorean_glass_is_dark_and_opaque` — `glass().car` after the swap passes `assert_dark_opaque` (helicopter too).
5. `test_delorean_drives_slower_than_compact` — the golden 4 s gas run ends between 18 and 25 m/s (flat-road estimate 21.1 with `stepCar`'s drag; compact 31.47).
6. `test_vehicle_query_selects_the_delorean` — `?vehicle=delorean` → `vehicle().model == 'delorean'`; `?vehicle=tank` → `'compact'`; no console errors.
7. `test_delorean_doors_open_on_the_start_screen_and_close_for_the_run` — on the start screen `doors().open` → > 0.95 and both `panelY` are higher than after Start, when `open` → < 0.05.
8. `test_delorean_rebuilds_free_gpu_memory` — five rebuilds of the delorean keep `gpu()` textures / geometries flat (the steel grain is shared, the plate is per-build).
9. If `prototype/tests/test_wheels.py` exists (#132 merged): the delorean reports 2 front + 2 rear wheels in `wheelYaw()` and steers.

Regression: the whole of `test_vehicles.py` (golden trace, #69 size, #123 glass), `test_heli.py`, `test_look_back.py`.
