# Brands, logos and permissions

Real places are the point of this game, and real places carry real brands. Logos are protected twice: as trademarks and as copyrighted artwork. A private build for the family needs nothing; a public repo and a public link need permission or a look-alike.

Not legal advice. Check before publishing.

## Rules for this repo

- No logo files in the repo until the owner has said yes in writing (email is fine). Keep the reply in a private folder, not in git.
- Until then: generic signage in the game ("Hallenbad", "Dorfladen"), or a parody look-alike.
- Reference photos from Google Street View, Apple, Bing: use only to look at while modelling. Never commit them, never texture from them (see [06-photo-capture.md](06-photo-capture.md)).
- Photos from sisseln.ch and other municipal sites: Gemeinde copyright. Reference is fine; textures need permission.
- Wappen (municipal coats of arms): public symbols, but many municipalities restrict use. Ask the Gemeindekanzlei.

## Who to ask

- **Gemeinde Sisseln**, Gemeindekanzlei: Sissila, Wappen, photos from sisseln.ch, the Kreisel. One email covers all four. Mention that the game is non-commercial and dedicated to a child from the village.
- **Häring, Eiken** (timber construction): plans and dimensions of the Plattform Sisslerfeld, which their apprentices designed and built. Same template, asking for plans instead of a logo.
- **Volg**, marketing: shop sign with the real logo. A small local game about the shop's own village is usually welcome; ask for written consent and any usage rules (colours, no alteration).
