# Changelog

All notable changes to this project are documented here, following
[Keep a Changelog](https://keepachangelog.com) and
[Semantic Versioning](https://semver.org).

Every entry carries the date and time it went live, in Swiss local time (Europe/Zurich).

## [Unreleased]

### Changed

- `2026-10-15 19:18` **Start screen** is tidier: the list of keys is gone from it. Press <kbd>F1</kbd> (or <kbd>?</kbd>) any time to see all keys.

### Added

- `2026-10-16 13:10` **+ Build your own world…** opens the **region editor** in a **new tab**, so the game stays where you left it.
- `2026-10-16 12:16` The start screen's **Worlds** row now ends with **+ Build your own world…**, which opens the **region editor**. The row stays even when no gallery worlds load, so the way to the editor is always there.
- `2026-10-14 11:31` The **region editor** now counts anonymously which **places** people frame and build: Gemeinde names, the frame size and a position rounded to about 5 km, never the exact frame. No cookies, no IP address stored, and nothing changes if you block it. The **Privacy** note sits under the map.

### Changed

- `2026-10-15 20:28` You can now **drive into the woods** and **between the trees**: the invisible wall at the forest edge is gone, every trunk stops the car like a post, and the **forest floor** is slower than the road.

### Fixed

- `2026-10-15 19:19` Der Hinweis "U · Pontonbrücke abbauen" erscheint nur noch in der Nähe der gebauten Brücke, nicht mehr irgendwo auf der Karte (zum Beispiel im Hübel-Tunnel). U baut die Brücke ebenfalls nur noch dort ab.
- `2026-10-14 11:16` In some **generated worlds** a **stream** lost its first metres of water and the browser console showed an error; streams now draw in full.
- `2026-10-14 09:19` In the **region editor**, "**Connection lost**, retrying…" now goes away as soon as the connection is back, instead of staying while your world is still building.
- `2026-10-14 06:55` The **region editor** keeps the right **place name**, takes the right **corner** when a frame is pulled inside out, says when a **world has expired**, sizes follow the **language region**, and **Space** downloads the world.
- `2026-10-13 21:02` The **autopilot** now blinks when it **leaves a roundabout**, not when it drives in; going round the ring it stays dark.
- `2026-10-12 21:40` In the **Eiffel room** the helicopter now really climbs: hold **Space** and it rises steadily (about 15 m per second) to the top of the tower in under 20 seconds, up to the ceiling; **Shift** brings it back down. Before, it crept up only about half a metre per second.
